# AceTrip 产品需求文档（PRD）

## 1. 产品概述

### 1.1 产品名称
AceTrip

### 1.2 Slogan
Game, Set, World

### 1.3 一句话定义
为 WTA 网球球迷打造的赛事旅行指南——追踪球员赛程、探索赛事城市、规划网球之旅。

### 1.4 目标用户
- WTA 女子网球球迷（核心用户）
- 有出境观赛意愿的旅行爱好者
- 关注球员动态、想了解赛事信息的普通网球迷

### 1.5 用户痛点
| 痛点 | 现状 | AceTrip 的解决方案 |
|------|------|-------------------|
| 赛事信息分散 | WTA 官网、ESPN、live-tennis 分别查 | 一站式聚合排名、签表、赛程 |
| 观赛旅行规划难 | 赛事城市的签证、交通、天气需要自己查 | 每个赛事自带旅行指南、天气、汇率 |
| 球员动态追踪不便 | 需要关注多个社媒和新闻源 | 关注球员 + Daily Feed 每日推送 |
| 无法可视化赛季行程 | 赛程只是文字列表 | 地图可视化 + 赛季时间轴 |

---

## 2. 产品定位

### 2.1 核心理念
> 赛程即行程——WTA 球迷的旅行不需要理由，只需要一张签表。

### 2.2 差异化
- **只做 WTA**：不做 ATP、不做综合体育，专注女子网球
- **旅行导向**：不是赛事数据工具，是"因为网球所以旅行"的生活方式产品
- **中文优先**：全站中文化，球员名、赛事名、城市名全部中文

### 2.3 不做什么
- ❌ 不做直播/转播
- ❌ 不做博彩/竞猜
- ❌ 不做社区/论坛（v1.0）
- ❌ 不做票务交易

## 3. 功能模块

### 3.1 首页
| 模块 | 说明 |
|------|------|
| Hero | Slogan "Game, Set, World" + 副标题 + 可交互 3D 地球（14 个赛事城市标注） |
| LIVE 标签 | 实时显示正在进行的赛事名称 |
| 功能特色 | 4 个核心功能入口卡片 |
| 球员排名 | 前 20 名球员横向滑动卡片 |
| 即将开赛 | 最近 4 场赛事倒计时卡片 |
| 四大满贯 | AO / RG / WIM / USO 独立展示 |
| 赛季总览 | 全年 33 场赛事时间轴 |
| Daily Feed | 每日 3 条 WTA 新闻 |
| 开发者彩蛋 | 底部手写体开发者寄语 |

### 3.2 球员图鉴
- 150+ 位 WTA 球员卡片
- 按排名排序，显示国籍、排名、积分
- 搜索和筛选
- 一键关注（需登录）
- 点击进入球员详情页（排名、积分明细、赛季战绩）

### 3.3 赛事中心
- 33 场 2026 赛季赛事
- 按级别分类（大满贯 / WTA1000 / WTA500 / WTA250）
- 赛事详情页：
  - 📋 签表（实时数据，中英文球员名）
  - 🌤️ 7 天天气预报
  - 💱 汇率换算（13 种货币，双向显示）
  - ✈️ 旅行指南（签证、交通、美食、住宿）
- 赛事心愿单（需登录）

### 3.4 互动地图
- Mapbox GL 3D 地图
- 关注球员的赛程路线可视化
- 心愿赛事标注
- 点击标记跳转赛事详情

### 3.5 用户系统
- 手机号 + 密码注册/登录
- 关注球员列表（云端同步）
- 赛事心愿单（云端同步）
- 意见信箱

## 4. 数据架构

### 4.1 数据源
| 数据 | 来源 | 更新频率 |
|------|------|----------|
| 球员排名 | live-tennis.cn（实时代理） | 实时 |
| 签表 | live-tennis.cn（实时代理） | 实时 |
| 球员信息/积分/战绩 | ESPN API + WTA API + live-tennis.cn | 每日 |
| 天气预报 | Open-Meteo | 实时 |
| 汇率 | Open Exchange Rates | 实时 |
| 新闻 | Google News RSS | 每日 |
| 用户数据 | Supabase PostgreSQL | 实时 |

### 4.2 数据更新机制
- **实时数据**：通过 Next.js API Routes 代理，用户访问时即时拉取
- **每日数据**：GitHub Actions 每日北京时间 8:00 自动抓取，更新 JSON 数据文件，自动部署

## 5. 技术方案

### 5.1 技术栈
- **前端**：Next.js 16 + React 19 + TypeScript + Tailwind CSS 4
- **地图**：Mapbox GL JS
- **数据库**：Supabase（PostgreSQL + Auth + RLS）
- **部署**：Vercel（CDN + Serverless Functions）
- **CI/CD**：GitHub Actions

### 5.2 项目结构
```
AceTrip/
├── src/
│   ├── app/              # 页面路由
│   │   ├── api/          # API Routes（draw/weather/news/rankings）
│   │   ├── login/        # 登录页
│   │   ├── players/      # 球员页面
│   │   └── tournaments/  # 赛事页面
│   ├── components/       # UI 组件
│   │   ├── layout/       # Header / BottomNav
│   │   ├── map/          # 地图相关
│   │   ├── players/      # 球员相关
│   │   ├── tournaments/  # 赛事相关
│   │   └── ui/           # 通用 UI
│   └── lib/              # 工具库（Supabase/Auth/Store）
├── data/                 # 静态数据文件（每日更新）
├── scripts/              # 数据抓取脚本
└── .github/workflows/    # GitHub Actions
```

## 6. 设计规范

### 6.1 色彩
| 名称 | 色值 | 用途 |
|------|------|------|
| Tennis Green | `#2D6A4F` | 主色 |
| Tennis Green Dark | `#1B4332` | 标题/深色 |
| Warm Cream | `#FDFBF7` | 页面背景 |
| Accent Yellow-Green | `#C5E063` | 强调色/地球标注 |
| WTA1000 | `#7C3AED` | 赛事级别标识 |
| WTA500 | `#0EA5E9` | 赛事级别标识 |

### 6.2 字体
| 字体 | 用途 |
|------|------|
| Noto Serif SC（思源宋体） | 标题、数据标签 |
| Inter | 正文 |
| Caveat | 开发者彩蛋（手写体） |

### 6.3 设计原则
- **中文优先**：所有文案中文化
- **呼吸感**：区域间距统一，留白充分
- **层次分明**：通过字号、颜色、间距建立信息层级
- **移动端友好**：响应式布局，底部导航栏
